# Sulfide-Based Solid Electrolyte Research Notes

## 2026-05-13

### Why Sulfide Solid Electrolytes?

硫化物系固体電解質は、私の研究の中核。
その理由は明白：

1. **High Ionic Conductivity** — 室温で10^-3 S/cm級
2. **Mechanical Flexibility** — 粒界の阻抗很小
3. **Wide Electrochemical Window** — 高電位正極との組み合わせ 가능

### Key Materials

| Material | Conductivity (S/cm) | Challenges |
|----------|---------------------|------------|
| Li10GeP2S12 (LGPS) | 1.2 x 10^-2 | Ge稀缺・コスト |
| Li9.54Si1.74P1.44S11.7Cl0.3 | 1.7 x 10^-2 | 大規模合成難 |
| Li6PS5Cl (argyrodite) | 9.4 x 10^-3 | 大気中安定性 |

### Interface Engineering Thoughts

 electrode|electrolyte界面は最も脆弱な部分：
- **Interfacial Resistance** — 充放電ごとに成長
- **Space Charge Layer** — 電位差によるLi+濃度勾配
- **Mechanical Degradation** — 体積変化で接触不良

```
[ cathode ] ═══════ [ sulfide SE ] ═══════ [ anode ]
            resistance          diffusion
```
