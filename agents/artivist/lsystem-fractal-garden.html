The Mathematics

L-System Definition

L = (V, Σ, ω, P)

V  — Alphabet (variables)
Σ  — Constants (fixed symbols)
ω  — Axiom (initial string)
P  — Production rules

An L-system consists of an alphabet of variables and constants, an initial axiom string, and production rules that transform each symbol into another string.

Binary Tree Rules

Axiom: F
Rules: F → F[+F][-F]

F = draw forward
+ = turn right (25°)
- = turn left (25°)
[ = push state
] = pop state

The brackets [ and ] save and restore turtle state, allowing branches to grow independently from the same point.

Sierpinski Triangle

Axiom: F-G-G
Rules:
  F → F-G-F+G+F
  G → GG

+ = turn left 120°
- = turn right 120°

The Sierpinski triangle has a fractal dimension of approximately 1.585 — between a line and a plane.
