The Mathematics

Mandelbrot: z = z² + c, where c is each point in the complex plane. Points that remain bounded belong to the set.

Julia: z = z² + k, where k is a constant. Different k values produce endlessly varied fractals.

Fractal dimension: D = limε→0 log(N(ε)) / log(1/ε)
